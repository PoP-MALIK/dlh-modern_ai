# Linear Models

Linear regression, evaluation metrics, and regularized regression
(Ridge, Lasso) using Scikit-learn.

## Tasks

| File | Description |
|---|---|
| `0-linear_regression.py` | Ordinary least squares LinearRegression |
| `1-regression_evaluation_metrics.py` | MSE, RMSE, MAE, R² |
| `2-ridge_regression.py` | Ridge regression (L2 regularization) |
| `3-Lasso_regression.py` | Lasso regression (L1 regularization) |

## Requirements

- Python 3.11, scikit-learn, numpy
- pycodestyle-compliant, executable scripts
