# Tree-Based Models

Builds, trains, and evaluates decision tree classifiers on the Wine dataset
using Scikit-learn.

## Tasks

| File | Description |
|---|---|
| `0-build.py` | Build an unpruned `DecisionTreeClassifier` (Gini impurity) |
| `1-train.py` | Train a classifier on `X, y` |
| `2-draw.py` | Print the trained tree's decision rules as text |
| `3-generate_predictions.py` | Generate predictions from a trained classifier |
| `4-evaluate.py` | Classification report (precision, recall, F1-score) |
| `5-pre_pruning.py` | Grid search for the best pre-pruning hyperparameters |

## Requirements

- Python 3.11
- `scikit-learn` 1.6.1, `numpy` 2.0.2
- All scripts follow `pycodestyle` and are executable
